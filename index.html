Overview

This app is a personal tool used to access Pinterest trend data via the Pinterest API. It is not available to the public and does not collect, store, or share any user data.

This app uses the Pinterest API solely to retrieve publicly available trend data for personal research purposes. API credentials are kept private and are not shared with any third party.

Third-party services

This app connects only to the Pinterest API. No other third-party services, trackers, or analytics tools are used.
